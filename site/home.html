Three keys from a full card to a short folder.

Lixa does one job: helping you decide. It doesn't import, catalogue or edit. It shows you the folder, remembers what you liked, and puts those files somewhere else.

01

O Open a folder

Thumbnails are 512px WebP, generated in Rust as you scroll, so a large folder opens without a long import. Subfolders show up in the sidebar.

02

L Mark the good ones

Step through full size with the arrow keys, zoom in to check focus, or flip the frame to black and white, sepia or invert.

03

E Export

Copy or move favourites into a new folder: everything, the current folder, or a chosen set of folders. The folder structure stays, unless you turn that off.

Margin notes.

Formats

JPEG, PNG, WebP, AVIF, TIFF, GIF, BMP and SVG. HEIC and HEIF are listed in the folder; preview depends on the system webview.

Slideshow

Play a folder, or just your favourites, at 2, 3, 5, 8 or 10 seconds a frame, with shuffle and loop. You can still mark frames from inside it.

Favourites

Grouped by the folder they came from, kept across sessions in a local SQLite file.

Find

Search by filename. Sort by name, date created or file size, either way. Resize the grid.

Private

No account, no cloud, no network calls. Files stay where they are until you export.

Bug reports

A local log file you can attach to an issue. Settings opens the folder that holds it.

Every action has a key.

Taken from the handlers in the app. O opens a folder on the gallery screen. E exports from the favourites page. L marks the focused thumbnail, or the frame open in the viewer and slideshow. The sidebar is Ctrl or ⌘ B, and fullscreen is F11. These stay quiet while a text field is focused.

# Nix — run without installing
nix run --accept-flake-config \
  github:santhosh-chinnasamy/lixa-gallery

# binaries cached on lixa-gallery.cachix.org
NixOS module 
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    lixa-gallery.url = "github:santhosh-chinnasamy/lixa-gallery";
  };

  outputs = { nixpkgs, lixa-gallery, ... }: {
    nixosConfigurations.myhostname = nixpkgs.lib.nixosSystem {
      modules = [
        ({ pkgs, ... }: {
          environment.systemPackages = [
            lixa-gallery.packages.${pkgs.system}.default
          ];
        })
      ];
    };
  };
}

The flake turns on the lixa-gallery Cachix cache. --accept-flake-config is what allows that. If a button has no direct file, it falls through to the latest release.
